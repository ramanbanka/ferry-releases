Copy, move, rename, delete. Quick Look works.

Setting up your phone

  1. Settings → About phone — tap Build number seven times
  2. Settings → Developer options — turn on USB debugging
  3. Plug in, unlock, and tap Allow

Once only. That prompt is Android asking whether to trust this particular Mac.
