# Ferry — releases

Download builds of Ferry here: **[Releases](../../releases)**.

Ferry mounts an Android phone on your Mac and shows it in Finder like a USB drive.

```bash
brew tap ramanbanka/ferry
brew trust ramanbanka/ferry
brew install --cask ferry
```

This repository holds published binaries only. Ferry's source is not public.

**Found a bug?** Open an issue here, and include your phone's model name and the output
of `ferry status`.
